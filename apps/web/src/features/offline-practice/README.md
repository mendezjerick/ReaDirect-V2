# Offline Practice boundary

Offline Practice is non-canonical.

The contracts, repository, download service, connectivity boundary, and entry
screens in this directory are for local, child-safe practice only. They must
not be used for scoring, progression, lesson completion, assessment evidence,
or delayed academic synchronization. Phase E renders only the validated local
allowlist, uses optional fixed Clara audio, and keeps recordings in memory for
the current screen. Active practice reads committed pack data and does not
fetch lesson content or submit local activity state.
