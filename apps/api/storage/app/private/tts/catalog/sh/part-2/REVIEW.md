# Part 2 Voice Review

These are the fixed, pre-generated Ma'am Clara lines used by Diagnostic
Assessment Part 2. Listen to the WAV files directly in the folders listed
below. If a delivery is unsuitable, regenerate that speech key without changing
its exact approved text unless the source-of-truth wording is intentionally
revised.

All current files are 48 kHz, mono, PCM 16-bit WAVs.
